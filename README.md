# OFF MUSIC 4.4.1

白いLiquid Glass UI、12分割の奥行きレーンを直接タッチする横画面音楽ゲーム。
左上のロゴはOFFとMUSICの間に3本のイコライザーを配置し、音の強弱とリズムを表します。
ロゴは曲一覧へ戻るボタンで、再生状態を示すインジケーターではありません。
プロセカの公式情報・動画から演奏の仕組みを調査し、独自の素材と自動譜面で実装。
[調査記録](REFERENCE_SEKAI.md) / [v4改修計画](V4_PLAN.md)。

**[アプリを開く](https://off-music.pinpon-fuuma.workers.dev)**

収録曲：歌詞付きの **Play & Pay / OFFSKU**。Glass CircuitはロビーBGMと旧URL互換用に保持。
提供音源・OFFSCREENキャラクターは本人の許可のもとに使用。他社ゲームの
キャラクター・音・ロゴ・譜面は使用しません。

## 遊び方

1. 最初のタップで起動音と小音量のロビーBGMを有効化。
2. 曲・難易度を選択。未ログインならGoogleかゲストを選択。
3. スマホを横向きにし、判定線に来るノーツの横幅の中を直接タッチ。
   **青＝タップ、緑の帯＝押したまま追って最後に離す、ピンクの矢印＝フリック**。
   ロングの終端に矢印がある場合は上へフリック。金色は強調ノーツ（2倍の重み）。
   同時押し・複数指に対応します。
4. PCは左から **A/S/D/J/K/L**。ロングはキーを押したまま、最後に離します。
   フリックは **Shift＋対応キー**。曲線ロングは隣のキーへ指を移して追います。
   PERFECT/GREAT/GOOD/BAD/MISS、FAST/LATE/ms/FLICK、スコア・コンボ・ライフを表示。
   GOOD/BAD/MISSでコンボが切れ、AP/FC継続中はコンボの色が変化します。
5. 初期はEASY/NORMAL/HARD、**Lv.5でEXPERT、Lv.8でMASTER**を解放。
   XP・レベル・称号・バッジ・テーマは継続。停止/回転/非表示で指を解除し、再開時は置き直します。
   ライフ0でも練習のため曲末まで続けられますが、その演奏はクリア扱いにしません。
6. 「曲を追加」から20MB・3秒〜10分のMP3/M4A/WAV/MP4等を解析。
   対応コーデックはブラウザによります。追加で30XP、同じファイルは1回。

**本体スピーカーで音ズレを感じる場合：設定→音でタイミングを測る。**
12回の音に合わせてタップし、最初の2回と外れ値を除いた中央値を保存します。
LATEが続くときは判定補正を＋、FASTは−。補正は入力判定だけに適用されます。
0.75/1/1.25倍速、楽曲・タップ音・BGM音量、振動、動きを減らす設定があります。

## 遊び方・得点（4.1）

選曲パネルのプレイボタン前に操作・加点の説明を常時表示します。「ルール・得点を詳しく見る」、
一覧下部の「遊び方・得点ルール」、一時停止中の「ルール・得点」から判定表と曲別の加点例を確認できます。
タップは同じ横位置を押す、スライドは保持と終端操作、フリックは矢印に合わせて指を動かす。
長押しは頭・途中の保持・終端がそれぞれ加点対象です。

| 判定 | 実時間のズレ | 基準点に対する得点 | コンボ |
| --- | --- | --- | --- |
| PERFECT | ±80ms以内 | 100% | +1 |
| GREAT | ±160ms以内 | 70% | +1 |
| GOOD | ±240ms以内 | 35% | 切れる |
| BAD | ±320ms以内 | 10% | 切れる |
| MISS | 範囲外・未操作 | 0% | 切れる |

近い判定から適用。判定幅を従来の2倍に拡大し、0.75/1/1.25倍速でも実時間の幅を保ちます。
音符の左右には0.85論理レーンの余裕（従来0.22）、画面の下70%で指の操作を受け付けます。
紫の帯は操作の目安で、線に指を厳密に重ねる必要はありません。遅れた音符も判定時間中は画面内に残します。
空振りでも小さな操作音と輪で反応しますが、得点は増えません。

満点は100万。基準点＝100万÷全判定の重みの合計、加点＝基準点×判定率×重み。
金色の重みは2、ほかは1。例：Play & Pay/NORMALは通常PERFECT約1,449点、GREAT約1,014点、金色PERFECT約2,899点。
スコアとXPは別です。完走20〜80XP（基本20＋スコア分最大40＋フルコンボ20）。
ルール画面とクライアント/サーバーの判定は共通定数を使用します。

## 操作チュートリアル（4.2）

選曲・ルールの「光るガイドで操作を試す」、または一覧下部の「操作チュートリアル」から、
ログインなしで **タップ→長押し→フリック** を実際に練習できます。一時停止中のルールからも開けます。

- 押す横位置を青/緑/ピンクで点灯し、指のアニメーションと合図音で案内。
- 音符の接近をカウントし、「いま、タップ！」「押したまま」「指を離す」「上へフリック」を表示。
- 練習の音符は判定線で待つため、操作を覚えるまで焦らず試せます。
- 成功したら「次の操作へ」。早く離す・場所が違う・フリックで動かさない場合は案内してやり直し。
- PCはSでタップ、Jを長押しして離す、Shift＋Kでフリック。実際の指の移動/保持を判定します。
- 横画面で全操作が収まり、縦は回転案内。回転/非表示による中断時はその操作をやり直せます。
- スコア・XP・人気・ランキングに加算せず、練習だけ何度でも再開可能。

Canvas描画・StageSession・許容範囲を本番と共有。案内の音符時刻を止めていても、
フリックの速さは独立した実時間で測るため、遅いドラッグを成功にしません。
練習を開いた元の選曲/ルールへ戻り、一時停止中の曲は時間も得点も進みません。
通常プレイの判定・譜面版はlanes-v4.1を維持します。

## 初回案内と長押し対策（4.3）

初めて使う端末・ブラウザでは、タイトル画面のスタート後にチュートリアルを自動で開きます。
右上の「スキップ」、縦画面の「いまはスキップ」、Escで途中終了できます。
完了は3操作の成功時点、スキップは終了操作の時点でこのブラウザに保存し、次の起動では自動表示しません。
一覧/選曲/ルールから何度でも練習可能。完了後に練習を途中終了しても完了履歴を保持します。
記録/曲のリセットやアプリの通常更新では初回案内の履歴を消しません。
ゲストも使えるlocalStorage方式で、Googleアカウントをまたいだ別ブラウザへの同期は行いません。
ブラウザデータを消すと初回扱いに戻ります。QAは専用のsessionStorageで検証し、本来の履歴に書き込みません。

チュートリアルと本番プレイ面・説明にはuser-select:noneとSafari用のプレフィックス、
-webkit-touch-callout:noneを適用。contextmenu/selectstart/dragstartと、プレイ領域内の残存選択を抑制します。
ゲーム内の別パネルにあるルール本文や入力欄は対象外です。
参考：[Apple Safariの長押しcallout仕様](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariCSSRef/Articles/StandardCSSProperties.html)、
[MDNのuser-select](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/user-select)、
[selectionchange](https://developer.mozilla.org/en-US/docs/Web/API/Document/selectionchange_event)。

## iPhoneでMP3がグレーアウトする場合（4.3.1）

音源選択は.mp3/.m4a/.wavなどの拡張子を明示し、audio/*ワイルドカードを使わない方式へ変更。
「曲を追加」の「すべてのファイルから選ぶ」はaccept属性を付けずに開く別の選択口です。
iCloud等で音源が形式判定から外れる場合に使えます。両方ともユーザーのクリックから同期的に開きます。

[WebKit #242110](https://bugs.webkit.org/show_bug.cgi?id=242110)には、iOS Safariでaudio/*が動画として扱われ、
MP3/M4A/WAVを選べなくする報告があります。本人画像の症状と現在のコードは一致しますが、
本人端末のiOS版は未確認で、この報告がその端末の直接原因と実機で断定したものではありません。
[accept仕様](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/accept)上もファイル選択のヒントであり、内容の検査を代替しません。
「*/*」も指定せず、代替選択ではフィルター自体を省きます。

File.typeが空/汎用でも拒否せず、実データをWeb Audioでデコードしてから解析します。
空ファイル/20MiB超は選択時に案内し、同じファイルを選び直す操作も可能です。
読み出し失敗と音声形式の非対応を分け、前者は「ファイル」アプリからのダウンロードを案内。
3秒〜10分/公開権チェック/認証/バックエンド容量制限は引き続き適用します。

## 曲の公開・ランキング

「曲を追加」は初期選択が **公開・サイト利用者全員**。Googleログインして権利確認→自動解析→アップロードすると、ゲストを含む全訪問者が遊べます。グループの作成・参加や管理者の作業は不要です。「非公開・自分だけ」「この端末だけ」も選択できます。

「自分の曲」または選曲画面の「公開範囲・削除」から、追加した本人がいつでも非公開・削除にできます。クラウドの削除は復元可能で、「最近削除した曲」から非公開へ戻せます。再公開には配信・再配布の権利確認が必要です。同じ音源を追加しても他人の所有権は取得しません。

非公開はログインした本人のみが再生でき、公開一覧・おすすめ・人気・順位から外れます。削除は本人の再生もできません。一覧・解析・音源は毎回公開状態を確認してno-storeで配信し、開始/終了時にも共有曲の状態を確認。公開済み音源が既に他人の端末に読み込まれた場合、そのコピーの回収はできません。
公開終了は開いたままの選曲詳細・曲別ルール・ログイン選択・プレイにも反映します。結果の個人履歴は残りますが、再プレイはできません。

全員が保存された同じ発音解析を取得し、端末ごとの再解析で譜面を変えません。選曲とプレイ開始時に正規解析を取得し、一覧は軽いメタ情報と波形のみ。以前の限定曲は勝手に全体公開せず、本人が「自分の曲」で明示的に公開できます。グループ作成・招待の画面は撤去し、互換APIだけを残しています。

- **曲別順位**：曲・難易度・譜面版ごとの自己ベスト。
- **ユーザー総合**：自己ベスト合計。重みは EASY 0.6 / NORMAL 1 / HARD 1.3 / EXPERT 1.6 / MASTER 1.8。
- **人気**：完了した演奏の累計。開始だけ、同じ結果の再送、QAでは増えません。チケット整理後も保持。
- **新着**：追加日の順。**おすすめ**：未プレイ、レベルに合うテンポ、新しさ、露出の少なさを考慮するルール式。
- **順位の特典**：同じ曲・難易度に3人以上、正確率50%以上で、初の表彰台+25XP、初の1位+60XP。
  それぞれ本人につき1回。称号バッジも付与します。
- **成長特典**：Lv.2フレーム、Lv.3サンセット/音楽好き、Lv.5 EXPERT/ネオン、Lv.8 MASTER/オーロラ、Lv.10ステージマスター。
  EXPERT/MASTERの解放はAPIでも検証。判定幅は全員共通です。

D1へ保存する前に、指ごとのdown/move/up/cancel、位置、ロングの追従/終端、フリックの動きを共通エンジンで再判定し、WebSocketで曲・順位・人気の更新を通知。
標準譜面・1倍速のみ順位へ反映。AI・テンポ調整・速度変更は練習。
v4はレーンと操作を変更したため、現在の判定は `lanes-v4.1` として旧版の順位と分けます。旧記録は個人履歴に残ります。

ゲストも全ての公開曲を遊び、公開ランキングを閲覧できます。Googleでクラウド保存、
曲の公開・非公開管理、ランキングへの記録、Workers AIが有効になります。過去のゲスト音源をログインだけで公開しません。
アカウントから自分のプレイ/追加曲をリセット・直前バックアップから復元できます。
R2音源はアーカイブし、他の人のデータは対象にしません。

## テストで記録を残さない

`/?qa=1` は画面上にQA表示を出し、追加音源はメモリ上のみ、結果・XP・人気・順位を保存しません。
アップロード公開と設定の保存も停止します。認証回避はなく、通常APIの権限は維持されます。
検証曲は歌詞付き。Sunoへの「80/180BPM」という生成指示は実際のBPMの保証ではなく、
生成後の音を解析して確認しています。検証音源は公開ライブラリへ残しません。

## 判定と音の同期

判定幅はOFF MUSIC独自の公開値：PERFECT ±80ms、GREAT ±160ms、GOOD ±240ms、BAD ±320ms、超過はMISS。
フリックの逆方向はPERFECTをGREATに制限しFLICKを表示。原作の非公開数値を再現したとの主張ではありません。
強調ノーツは重み2、得点は全判定の重みから100万点へ正規化。


旧版にあった発音位置のBPMグリッドへの丸めと固定オフセットを廃止。
22,050Hzへアンチエイリアス付きでリサンプルし、低/中/高3帯域のエネルギー変化を
約3ms単位で検出、局所的なアタックまで遡ります。難易度/AIは実際の発音候補の
採用数を変え、開始する発音時刻は動かしません。推定主音は打音の調律に使います。
ロングの始終点は実測候補から選び、内部に拍間隔のチェックポイントを置きます。
横位置/可変幅/2本の指で取れる配置/曲線/フリック/同時押しは決定的に生成されます。
発音候補から拍の細分ごとに強い候補を選び、難易度に合わせて密度を変えます。
複雑な歌入り曲ではspectral flux + BeatRoot（music-tempo）でもテンポを推定。
4拍分の見える範囲を `240 / BPM / 流速倍率` 秒（音源時間）で計算し、再生倍率も
見た目の速さに反映します。BPMは表示と選音密度、発音位置は実測時刻、入力補正は判定だけに使います。
半分/倍の曖昧さが残るため候補を表示し、練習時は調整できます。
音楽の全てのビートやテンポ変化を完全に推定する機能ではありません。

`getOutputTimestamp()` の音声出力時計を描画と入力の基準に使用。
入力イベントの発生時刻を用いるので、メインスレッドの処理待ちを遅れとして
加算しません。非対応時はbaseLatency+outputLatencyから推定します。
入力補正と見た目の時計を分け、一時停止・再開でも時計が巻き戻らないようにします。

既知の120BPM・3帯域28音の信号試験：**28/28検出・音域28/28、
中央値1.4ms、95パーセンタイル2.7ms、最大2.9ms**。
これはソフトウェアの発音検出誤差で、スマホ実機の総遅延の測定ではありません。
楽曲解析は推定で、歌声・複雑な伴奏や機器の遅延を完全に除去する保証はありません。
[測定結果](evidence/timing-v2.json)、[歌詞付き検証](evidence/v3-vocal-audit.json)、[v4計画](V4_PLAN.md)。

## 技術選定と理由

| 技術 | 選定理由 |
| --- | --- |
| React・TypeScript | 選曲、解析、演奏、結果、ログイン、曲の管理を型で接続。 |
| Vite | SSRを要しないゲームを静的ビルドし、解析Workerを別ファイルへ分離。 |
| CSS・Motion | 透明な白いGlass、タイトル・シート・通知・キャラクターの動き。OSとアプリの動き軽減設定を尊重。 |
| Manrope・DM Sans・Noto Sans JP | 大きな英字、数字、読みやすい日本語を揃える。失敗時はシステムフォント。 |
| Canvas 2D・透視投影 | 台形の12分割レーン、ベベル付き可変幅ノーツ、曲線リボン、粒子を毎フレーム描画。Web Audioの時計を直接使い、ReactのUI更新と分離。ブラウザ向けの小さい配信を保つため、Unity WebGLへの置換はしない。 |
| Pointer Events・共通判定エンジン | 指をIDで区別し、位置/保持/移動/リリースを記録。マルチタッチ、Pointer Capture、cancelを処理し、同じ入力をサーバーでも再判定。 |
| Web Audio API・OfflineAudioContext | 出力時計への同期、アンチエイリアス付き解析用リサンプル、調律された3種類の打音、独自ファンファーレ。 |
| music-tempo（MIT） | 複雑な歌入り曲のテンポをspectral fluxとBeatRootで照合。軽量なWorker内実行でサーバー推論コストなし。全音源の正解BPMを保証しない。 |
| Web Worker・3帯域DSP・軽量FFT | 音源の発音とエネルギーを端末内で解析し、重い処理中もUIを操作可能に。FFTは主音の推定に使用。 |
| IndexedDB・idb | ローカルの音源Blob、解析、成績、ゲスト成長をリロード後も保持。 |
| Hono・Zod | 軽量APIと、ファイルサイズ・解析・打鍵記録などの入力検証。 |
| Workers Static Assets | 画面・初期曲・キャラクターを静的配信。 |
| Cloudflare D1 | ユーザー、セッション、設定、成績、XP、グループ、順位、プレイチケットを保存。トリガーと一意制約でXPの重複を防止。 |
| Cloudflare R2 | 明示的に共有した音源だけを保存。公開バケットURLは使わず、APIで参加権限を毎回検証。 |
| Durable Objects・WebSocket Hibernation | グループごとの更新を複数画面へ即通知し、待機中のCPU常駐を避ける。 |
| Workers AI | 数値化されたエネルギーから16区間の譜面密度を生成。精密な音符の時刻はDSPが担当。 |
| Google Identity Services・jose | Googleのみの認証とJWT署名・iss・aud・exp・nonceの検証。基本プロフィール以外の権限は不要。 |
| Lucide | 一貫したSVGの操作アイコン。 |
| Vitest・実SQLite | 判定・解析・速度・成長・権限・共有・ランキング・重複再送を再現可能に検証。 |
| Suno | 既存Pro枠内で独自のテスト曲を作成し、提供曲以外のリズムでも確認。 |
| Imagegen | 添付画像の4キャラクターを透明なアトラスへ切り出し。SVGで個別クリップし、CSSで動かす。 |

## 無料範囲を意識した上限

新しい有料プラン・クレジットの購入はしていません。Cloudflareの既存アカウントを使用。

- 共有音源20MiB/曲、公開曲100曲・限定グループ20曲、200MiB/領域、アプリ全体500MiB。
- 旧互換APIのグループ全体20、作成者ごと3、メンバー50。公開ライブ接続100。
- 削除・リセットは復元用の音源を保持するため、保存バイト容量には引き続き算入します。
- AIは1人5回/日・全体30回/日、240出力トークン。失敗も利用回数へ含む。
- 曲追加XPは同一ファイルにつき1回、ログイン時は直近24時間で5曲まで。
- プレイ保存は1人100回/直近24時間・全体1000回。端末の曲と結果はIndexedDB。
- 個人クラウド成績は最新300件。演奏チケットは7日で整理、完了後の譜面は解放。

## 開発・配置

Node.js 24以上。

```sh
npm ci
npm run build
npm run db:local
npm run preview
```

`http://localhost:8797`。ホットリロードは別ターミナルで `npm run dev`。

```sh
npm test
node scripts/audit-timing.mjs
npm run build
```

自分のアカウントへ置く場合は `wrangler.jsonc` のaccount_id・D1 ID・R2名・
APP_ORIGIN・GoogleクライアントIDを交換し、D1とR2を作成。
Googleの承認済みJavaScript生成元へ公開URLと必要なlocalhostを追加します。
シークレットは使用しません。`npm run db:remote` → `npm run deploy`。
Durable ObjectはSQLiteクラスのmigrationで作成されます。
